HomeRP ORFK weboldal
=====================

A csomag minden fájlja egyetlen mappaszinten használható, nincs szükség almappákra.

Fájlok:
- index.html
- buntetesek.html
- szabalyzat.html
- rolunk.html
- belepes.html
- styles.css
- data.js
- app.js

Használat:
Nyisd meg az index.html fájlt, vagy töltsd fel az összes fájlt ugyanabba a webes gyökérmappába.
GitHub Pages alatt a statikus oldal működik.

A személyzeti belépés jelenleg látvány/demo. Valódi hitelesítéshez szerveroldali backend szükséges.
